# Support

Nimbus support is handled through GitHub issues and discussions.

## Before Asking for Help

- Check existing issues.
- Try the latest upstream-stable build that matches your setup, if Nimbus has not
  published a stable release yet.
- Export logs from the Web UI when possible.
- Remove secrets, tokens, private hostnames, and public IP addresses from logs
  before posting.

## Good Bug Reports Include

- Nimbus commit or release.
- Whether you are using a source build, portable build, or installer.
- Host OS version.
- GPU model and driver version.
- Client device, client app, client version, resolution, FPS, bitrate, codec, and
  HDR setting.
- Capture mode and virtual display setting.
- Clear reproduction steps.
- Logs or crash bundle when relevant.

## Where to Report

- Use a bug report issue for reproducible defects.
- Use a crash report issue for crashes with a crash bundle.
- Use a feature request or discussion for new ideas.
- Use the security policy for vulnerabilities.

## Scope Limits

Nimbus cannot provide guaranteed real-time support. Hardware-specific streaming
issues often require reproduction from users who own the affected GPU, display,
client, or network setup.
